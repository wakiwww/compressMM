## 🚀 上传步骤

### 第一步：选择文件
**建议从最简单的开始**：
```bash
# 使用最简版本
使用文件: App_Territories_Minimal.geojson
```

### 第二步：App Store Connect 操作顺序
1. **登录**: https://appstoreconnect.apple.com
2. **我的 Apps**: 选择 "werck it!- video degrader（压烂它！）"
3. **功能**: 点击 "价格与销售范围"
4. **地区**: 点击 "管理地区" **（关键步骤！）**
5. **上传**: 点击 "选择文件"，选择 `.geojson` 文件
6. **预览**: 查看地图显示是否正确
7. **保存**: 点击 "完成"

## ⚡ 故障排除

### 1. 浏览器问题
- **尝试 Chrome** (推荐)
- 清除缓存: `Cmd+Shift+R` (Mac) / `Ctrl+Shift+R` (Windows)
- 使用无痕/隐私模式
- 禁用浏览器扩展

### 2. 文件问题
- **确保扩展名**: `.geojson` (不是 `.json`)
- **文件大小**: 所有文件 < 2KB ✅
- **文件编码**: UTF-8 ✅
- **格式验证**: 所有文件已验证 ✅

### 3. App Store Connect 问题
- **确认应用状态**: 应用必须存在且未下架
- **检查权限**: 确保有"管理"权限
- **重新登录**: 退出重新登录 App Store Connect

### 4. 网络问题
- 稳定的网络连接
- 避免 VPN
- 尝试不同网络环境

## 📝 详细错误诊断

### 如果仍然失败：
1. **截图错误页面** - 包含完整错误消息
2. **记录时间** - 发生时间
3. **浏览器信息** - Chrome 版本等
4. **网络状态** - 网络是否稳定

### 常见错误原因：
1. **格式错误**: 使用我的已验证文件 ✅
2. **权限不足**: 检查 App Store Connect 权限
3. **应用状态**: 确保应用是"准备提交"状态
4. **系统维护**: App Store Connect 可能正在维护
