# 视频降质 App 设计清单
> 目标平台：iOS 18+（SwiftUI）
> 风格定义：极简黑白科技感，参考 Apple Human Interface Guidelines 2024

---

## 一、应用定位

- 功能：将视频压缩成"阴间"风格，支持多种降质模式（类似胶卷选择）
- 音频同步处理：视频压缩的同时对音频进行对应风格的降质
- 核心交互：滑块控制阴间程度，超阈值时弹出警告

---

## 二、视觉风格规范

### 配色
- 背景：纯黑 `#000000`
- 主文字：纯白 `#FFFFFF`
- 次要文字 / 描述：`#888888`
- 强调色（唯一彩色元素）：`#FFFFFF` 或冷白发光效果，禁止使用彩色
- 分割线：`#1C1C1C`
- 卡片背景：`#0A0A0A`
- 警告色：`#FF3B30`（仅用于超阈值警告）

### 字体
- 主字体：SF Pro Display（系统字体，iOS 原生）
- 标题：SF Pro Display Bold，28pt
- 副标题：SF Pro Display Medium，17pt
- 正文 / 说明：SF Pro Text Regular，15pt
- 标签 / 数值：SF Mono，13pt（用于参数数值显示，营造科技感）

### 圆角 & 间距
- 卡片圆角：`cornerRadius: 16`
- 滑块轨道圆角：`cornerRadius: 8`
- 页面左右边距：`20pt`
- 组件垂直间距：`16pt`

### 动效
- 页面切换：`.easeInOut(duration: 0.25)`
- 滑块拖动：实时响应，无延迟
- 警告出现：`.spring(response: 0.4, dampingFraction: 0.7)`
- 模式选择卡片切换：scale 轻弹动效，选中时微微放大 `scaleEffect(1.03)`

## 三、界面结构

### 1. 主页面（Home）

```
┌─────────────────────────────────┐
│  [状态栏]                        │
│                                 │
│  DECAY                          │  ← App 名，大号 Bold，左对齐
│  视频降质工具                    │  ← 副标题，灰色
│                                 │
│  ┌─────────────────────────────┐ │
│  │  + 导入视频                  │ │  ← 虚线边框卡片，点击触发相册选择
│  │  点击或从相册选取              │ │
│  └─────────────────────────────┘ │
│                                 │
│  [视频预览缩略图（导入后显示）]    │
│                                 │
└─────────────────────────────────┘
```

- 导入按钮：虚线边框（`strokeStyle: dash: [6]`），白色虚线，黑色背景
- 导入后显示视频缩略图 + 时长 + 文件大小
- 底部固定「开始处理」按钮（导入视频后激活）

---

### 2. 模式选择（Mode Picker）

水平滚动卡片列表，类似胶卷选择器。

#### 模式列表

| 模式名 | 英文标识 | 视频降质方式 | 音频降质方式 |
|--------|----------|-------------|-------------|
| 地下录像 | `BASEMENT` | 超低码率 + 强烈块状压缩噪声 | 降采样至 8kHz，大量杂音 |
| 磁带损坏 | `VHS` | 模拟 VHS 抖动 + 色彩偏移 + 扫描线 | 模拟磁带哇音，轻微失真 |
| 深海信号 | `SIGNAL` | 马赛克 + 帧丢失 + 随机花屏 | 数字断续感，卡顿噪声 |
| 核辐射 | `FALLOUT` | 严重过曝 + 高对比 + 颗粒感 | 高频噪音叠加，沉闷感 |
| 古早网络 | `DIALUP` | 极低分辨率 + 高压缩比 + 低帧率 | 降至 16kHz，mp3 极低码率感 |
| 末世广播 | `BROADCAST` | 随机静帧 + 信号条纹 + 色偏 | 模拟无线电杂音 |

#### 卡片设计
- 尺寸：`140 × 180pt`
- 背景：`#0A0A0A`，选中时白色描边 `1.5pt`
- 顶部：模式英文名，SF Mono，11pt，灰色
- 中间：抽象图标或纹理预览（黑白风格 SVG 图标）
- 底部：中文模式名，SF Pro Medium，15pt，白色
- 未选中：透明度 `0.5`，选中：`1.0` + 描边

---

### 3. 阴间程度控制（Decay Slider）

```
┌─────────────────────────────────┐
│  阴间程度                        │
│                                 │
│  ●━━━━━━━━━━━━━━━━━━━━━━━━━○    │
│  轻度降质              极致崩坏  │
│                                 │
│  当前：67%   [!] 超过80%将严重   │
│              损坏文件可读性      │
└─────────────────────────────────┘
```

- 滑块轨道：左侧白色填充，右侧 `#333333`
- 滑块手柄：纯白圆形，直径 `24pt`，轻阴影
- 左标签：`轻度降质`，右标签：`极致崩坏`，均为灰色 12pt
- 数值显示：SF Mono，右对齐，实时更新
- 超过 80%：轨道末端变红，弹出内联警告文字（非弹窗）
- 超过 95%：弹出 Alert 二次确认

#### 警告文案
- 80%-95%：`⚠ 压缩量较大，输出文件可能产生严重失真`
- >95%：Alert 标题「确定继续？」，正文「当前参数可能导致视频完全不可辨认，音频严重损坏。」，按钮「继续压烂它」/ 「取消」

---

### 4. 音频控制（Audio Section）

折叠卡片，默认展开。

```
┌─────────────────────────────────┐
│  音频处理          [跟随视频 ▾]  │
├─────────────────────────────────┤
│  音频降质程度                    │
│  ●━━━━━━━━━━━━○                 │
│  轻微               损毁         │
│                                 │
│  ○ 跟随视频模式   ← 默认        │
│  ○ 独立调节                     │
│  ○ 保留原始音频                  │
└─────────────────────────────────┘
```

- 默认：音频跟随视频模式自动降质
- 独立调节：出现独立音频滑块
- 保留原始音频：音频不做处理

---

### 5. 输出设置（Output）

紧凑列表，圆角卡片内。

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 分辨率上限 | 跟随模式 | 可手动设定最大分辨率 |
| 帧率 | 跟随模式 | 可锁定为 12fps / 24fps / 原始 |
| 格式 | MP4 (H.264) | 固定，不提供选项（保证最大兼容性） |
| 保存位置 | 相册 | 相册 / 文件 App |

---

### 6. 处理页面（Processing）

全屏黑色背景，中心动效。

```
┌─────────────────────────────────┐
│                                 │
│                                 │
│         ████████░░░░  67%       │  ← 进度条，白色填充
│                                 │
│         正在降质中...            │
│         BASEMENT 模式           │
│                                 │
│         预计剩余 12 秒           │
│                                 │
│              [取消]              │
└─────────────────────────────────┘
```

- 进度条：细线风格（高度 `2pt`），白色，无圆角
- 文字：居中，动态省略号动效
- 取消按钮：灰色文字，无背景

- 分享按钮：描边风格（白色 `1pt` 边框）

## 四、导航结构

```
App 启动
  └── 主页（视频导入）
        └── 编辑页（模式选择 + 滑块 + 输出设置）
              └── 处理页
                    └── 完成页
                          ├── 返回主页
                          └── 预览对比（模态弹出）
```

- 导航栏：透明背景，白色返回箭头，无标题（页面内大标题）
- 无 Tab Bar（单流程线性体验）

---

## 五、交互细节

- 所有按钮点击：`UIImpactFeedbackGenerator(.light)` 触觉反馈
- 滑块超过 80%：`UINotificationFeedbackGenerator(.warning)` 触觉反馈
- 处理完成：`UINotificationFeedbackGenerator(.success)` 触觉反馈
- 深色模式：强制深色（`UIUserInterfaceStyle = .dark`），不跟随系统
- 横屏：锁定竖屏（`UIInterfaceOrientationMask = .portrait`）

---

## 六、Xcode 项目配置建议

- iOS Deployment Target：**iOS 17.0+**
- UI Framework：**SwiftUI**（主体）+ UIKit（触觉反馈 / 视频处理）
- 视频处理框架：**AVFoundation**（压缩）+ **Core Image**（滤镜效果）
- 音频处理：**AVAudioEngine** 或导出时通过 `AVAssetExportSession` 控制音频码率
- 权限声明（Info.plist）：
  - `NSPhotoLibraryUsageDescription`：「需要访问相册以导入和保存视频」
  - `NSPhotoLibraryAddUsageDescription`：「需要保存处理后的视频到相册」
